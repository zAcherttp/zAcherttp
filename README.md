## Selected projects

- [Session Hub](https://github.com/zAcherttp/session-hub) — a SwiftUI macOS app
  for managing Claude Code sessions across Desktop accounts and the CLI. Move,
  share, stash, fork, and resume sessions with backups and undo.
- [claude-fleet](https://github.com/zAcherttp/claude-fleet) — a Claude Code plugin
  for queuing parallel tasks, tracking file overlaps, and coordinating sessions.
- [electron-boilerplate](https://github.com/zAcherttp/electron-boilerplate) — an
  Electron foundation with React, Vite, Hono, typed IPC, packaging, and tests.
- [miniclaw](https://github.com/zAcherttp/miniclaw) — a local personal assistant
  built with LangGraph, with Telegram and command-line interfaces.
- [Northstar WMS](https://github.com/zAcherttp/next-wms) — a warehouse operations
  demo with Convex data, inventory workflows, reports, and a 3D layout editor.
